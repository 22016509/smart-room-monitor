Sensor configuration
  • DHT22: temperature and humidity
  • Photoresistor (LDR): light level
  • ESP32 ADC: 12-bit reading (0–4095)

How to interpret the readings

  • Temperature is displayed in degrees Celsius.
  • Relative humidity is displayed as a percentage.
  • Light is shown as a raw analogue-to-digital converter (ADC) value. The exact value depends on the LDR circuit and room lighting.
  • This dashboard currently generates sample values in the browser. Real sensor data requires a connected ESP32 and a configured data connection.
